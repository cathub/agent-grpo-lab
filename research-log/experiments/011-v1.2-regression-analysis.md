## Prompt-induced Action Bias: evidence versus hypothesis

VERIFIED: parsed top-level tool fields increase extraction 14→109/160 and comparison 8→147/160. These counts include mixed invalid envelopes; they are not executed tool counts and omit unparseable text. Extraction superfluous accepted-form calls rise 14→97, comparison 6→56. The data was already supplied in both categories. The 12 extraction regressions that become needless calls are direct behavioral examples.

HYPOTHESIS: stronger shared tool-calling instructions and the preserved tool-only example bias the model toward actions even when finalization is appropriate. This is consistent with the observed direction but not established as the unique cause. The new prompt also changes length, wording, ordering, negative examples and emphases; no factorial intervention isolated them. Alternative explanations include small-model instruction competition, copying the example, or interpreting observation IDs as a cue to call tools. Do not call the hypothesis a confirmed internal mechanism.

The instructions explicitly say to use already supplied data, so this is not an intentional requirement to call tools on extraction tasks. Observation-shaped replies and string values show that action bias alone cannot explain all regressions.

## Limitations and next decision

Known metric/winner shortcut, 2142/2143 task dates versus a generic 2024 example, small held-out set, shared templates and mixed task-completion definitions persist. Comparison claims remain confounded. No test result was used to retune a prompt here. The read-only audit does not add causal certainty or new learned capability.

Recommended next decision: preserve v1.2 as a negative/mixed result, test a shorter capability-specific direct-answer versus tool-action prompt on training/validation only in a separate experiment, and independently fix ranking shortcuts in a future benchmark version before broad GRPO claims. Only selection currently supplies mixed training groups; no training is authorized by this audit.
